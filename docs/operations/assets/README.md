# Activos visuales del manual de operador de Rafa

Estos archivos respaldan el PDF de capacitación construido a partir del borrador
RAFA_OPERATOR_MANUAL_DRAFT.md ubicado en el directorio superior. Son material de
operación y capacitación; no son diagramas eléctricos, de cableado ni instrucciones
de mantenimiento.

| Archivo | Uso |
| --- | --- |
| rafa-cover-no-person.png | Fotografía de portada. Edición no destructiva de una foto aportada por el propietario: se eliminó la persona parcialmente visible y los plásticos colgantes de las dos patas delanteras. |
| rafa-radio-controls-original.png | Fotografía original de la radio FlySky FS-i6 aportada por el propietario, conservada como referencia de procedencia. |
| rafa-radio-controls-clean.png | Fotografía limpia de la misma radio, usada en el PDF con óvalos y rótulos vectoriales para joystick izquierdo, CH5 y CH6. No autoriza reconfigurar la FS-i6. |
| rafa-radio-controls-schematic.svg | Esquema anterior conservado como activo histórico; no se usa en la edición actual del PDF. |
| rafa-vista-trasera-original.png | Fotografía a color de Rafa vista desde atrás, aportada por el propietario. |
| rafa-vista-trasera-anotada.svg | Lámina anterior conservada como activo histórico; la edición actual usa la fotografía original con anotaciones vectoriales integradas en el PDF. |
| rafa-bomba-y-brazos.png | Fotografía de referencia de bomba, mangueras y brazos de aspersión. |

La orientación izquierda/derecha de la lámina trasera se refiere a la **imagen vista
desde atrás**. El operador no abre las cajas ni interviene ninguno de sus componentes.
El pulsador rojo/amarillo es un paro de tracción: no detiene la motobomba ni constituye
el aislamiento eléctrico total.

Antes de liberar el manual para trabajo de campo, el responsable debe confirmar
físicamente las etiquetas de batería e inversor y completar las demás condiciones de
liberación registradas en el manual.
